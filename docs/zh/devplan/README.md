# mindloop L3 大脑 —— 开发计划（索引）

本目录存放 L3 认知大脑的分阶段开发计划。**L1/L2 执行暂缓** —— 其设计复用
Brain2Robot；整个 L3 开发期唯一机身是 `bodylink` 的 `MockBody`。

| 文档 | 内容 |
|---|---|
| [DEV-PLAN.md](DEV-PLAN.md) | 完整分阶段计划（P0–P6）、里程碑、风险、排期 |

## 一览

```
P0 契约 ─► P1 意图+规划 ─► P2 Episteme ─► P3 Phylax ─► P4 痕迹+重规划 ─► P5 全回路 ─► P6 生产化
```

| 阶段 | 主题 | 里程碑 |
|---|---|---|
| P0 | 缝契约 + 测试脚手架 | —（基本完成） |
| P1 | 意图路由 + 规划骨架 | M-L3.1 |
| P2 | Episteme 技能卡库 | M-L3.2 |
| P3 | Phylax 策略层 | M-L3.2 |
| P4 | L4 痕迹 + 重规划 | M-L3.3 |
| P5 | 对话 + 完整 S2 回路 | M-L3.3 |
| P6 | 生产推理器 + 评测 + 云启动 | M-L3.4 |

**依据：** 决策 D1–D5 + K1–K3 与本体契约 B1–B10 见
[../brain-architecture.md](../brain-architecture.md)。每个阶段先查对应的
Brain2Robot 设计文档。每个阶段先 spec 再码。
